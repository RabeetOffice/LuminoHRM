# Lumino HRM Phase 6b (Performance) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** HR keeps KPIs per designation or person, opens a review cycle each quarter (or month), and every eligible person gets a review with a frozen copy of their KPIs; the employee self-rates (optional), the manager rates, HR closes; scores are weighted and frozen at close; people see what they may and nothing earlier; closed reviews are history on the profile.

**Architecture:** Three layers. (1) **Records:** `kpis`, `review_cycles`, `reviews`, `review_scores` (the snapshot); scores in integer hundredths. (2) **Actions** (`App\Actions\Performance`): one transaction each, `DB::transaction(fn, 3)`, cycle row first then review row (see spec 5.9), state re-checked under the locks, audit in the same transaction; the state table lives in one class (`ReviewStates`) and the who-may rules in one class (`ReviewAccess`), so no screen or action re-implements them. (3) **Screens:** KPIs, Reviews (cycles list for HR, team list for managers), cycle page, review page, My Reviews, profile tab, dashboard card.

**Tech Stack:** As Phases 0 to 6a (Laravel 13, PHP 8.4, Inertia + React + TypeScript, Tailwind 4, shadcn/ui, Wayfinder, spatie permission + activitylog, Pest, Vitest). No new packages.

**Spec:** `docs/superpowers/specs/2026-11-26-phase-6b-performance-design.md` (wins where it differs from the main design) and `docs/superpowers/specs/2026-11-23-lumino-hrm-design.md` sections 8 (roles), 9.2 (profile tabs), 9.6 (Performance), 11 (data model).

**Builds on:** Phases 3 to 6a as built on `main`. Code this phase reads: `App\Support\{EmployeeAccess, Settings}`, `App\Support\Attendance\AttendanceClock`, `App\Support\Audit\Audit`, `App\Support\Payroll\PayrollAccess` (the sole-active-Admin idea), `App\Support\Leave\{LeaveRouting, WaitingForMe}` (manager routing and the "waiting for me" shape), `App\Http\Controllers\Settings\HrmSettingsController` + `App\Http\Requests\Settings\{SettingsGroupRequest, LeaveRequest}` + `resources/js/components/settings/{leave-panel,settings-form,fields}.tsx` (a Settings group), `App\Http\Controllers\Settings\AssetCategoryController` + `settings-nav.tsx` (n/a here), the Assets tab and `assets-panel.tsx` (a profile tab), `App\Support\Assets\DashboardAssets` and `DashboardController` (a dashboard card), `App\Http\Resources\EmployeeProfileResource`, `App\Actions\Employees\DeleteEmployee`, `App\Models\Designation::deleteBlocker`, `tests/Feature/Assets/AssignmentLockOrderTest.php` (the statement-order technique).

- Every action exposes `handle(...)` (the transaction) and a `within(...)` (checks and writes, caller holds the locks). Common shape: plain read of the cycle id, cycle row `sharedLock`, review row `lockForUpdate`, re-read; refuse when the cycle is closed ("This cycle is closed."), then the actor check (`ReviewAccess`, `AuthorizationException` so the controller answers 403), then the state check, then the write, then the audit.
    - `SaveSelfRatings::handle(User $by, Review $r, array $ratings): Review` (state `self_review`; the reviewee only) and `SaveManagerRatings::handle(User $by, Review $r, array $ratings, ?string $overallComment): Review` (state `manager_review`; `ReviewAccess::mayRate`). `$ratings`: `[score row id => {rating: ?int 1-5, comment: ?string up to 1,000}]`; ids must belong to the review ("Those ratings do not belong to this review."); partial saves allowed (drafts); no audit; no state change.
    - `SubmitSelfReview::handle(User $by, Review $r, array $ratings): Review`: saves, then requires every row rated ("Rate every KPI from 1 to 5 before submitting."), sets `self_score` (`ReviewScoring::selfScore`), `self_submitted_at`, state `manager_review`. Audit `Self-review submitted` (`self_score`).
    - `WaiveSelfReview::handle(User $by, Review $r): Review`: `ReviewAccess::mayManage`; `self_review` only; state `manager_review`. Audit `Self-review waived`.
    - `SubmitManagerReview::handle(User $by, Review $r, array $ratings, ?string $overallComment): Review`: saves, requires every row rated (same message), state `ready_to_close`, `manager_submitted_at`, clears `send_back_note`. Audit `Manager review submitted` (`manager_score` preview, `own_review` when the sole-manager exception applied).
    - `SendBackReview::handle(User $by, Review $r, string $note): Review`: `mayManage`; `ready_to_close` only; note required ("Write a note for the manager.", up to 500); state `manager_review`; keeps ratings; `manager_submitted_at` cleared. Audit `Review sent back` (`note`).
    - `CloseReview::handle(User $by, Review $r): Review`: `mayManage`; `ready_to_close` only; sets `final_score` = `ReviewScoring::managerScore`, `closed_at`, `closed_by`, state `closed`. Audit `Review closed` (`final_score`, `label`, `own_review`).
    - `ReopenReview::handle(User $by, Review $r): Review`: `mayManage`; `closed` only; the cycle must be open ("This cycle is closed, so its reviews cannot be reopened."); clears `final_score`, `closed_at`, `closed_by`; state `ready_to_close`. Audit `Review reopened` (`previous_score`).
    - `SkipReview::handle(User $by, Review $r, string $reason): Review`: `mayManage`; from `self_review`, `manager_review` or `ready_to_close`; reason required ("Give a reason for skipping.", up to 500); `skipped_from` = the old state. Audit `Review skipped` (`reason`, `from`).
    - `RestoreReview::handle(User $by, Review $r): Review`: `mayManage`; `skipped` only, cycle open; state = `skipped_from`; clears `skip_reason`, `skipped_from`. Audit `Review restored` (`to`).
    - `ChangeReviewer::handle(User $by, Review $r, ?int $reviewerEmployeeId): Review`: `performance.manage` (the reviewee of an HR review changing their own reviewer is refused like any own action); any state but `closed`; the person must have an active login holding `performance.review-team` and not be the reviewee ("{name} cannot review this person: they need an active login with review access." / "Nobody can review themselves."); null means HR; "The reviewer is already {name}." when unchanged; closed: "A closed review's reviewer cannot be changed." Audit `Review reviewer changed` (`old` / `attributes` of reviewer name or "HR").
- `ReviewScoring::weighted`: `intdiv(2 * 100 * Σ(rating × weight) + Σweight, 2 * Σweight)` (half up, integers only); rows without a rating are left out of both sums for a preview and refused at submit and close.
- **Routes** (auth only; `ReviewAccess` decides, 403 otherwise; all `whereNumber('review')`): `performance.reviews.self-draft` `PUT performance/reviews/{review}/self`, `.self-submit` `POST .../self/submit`, `.waive` `POST .../waive`, `.manager-draft` `PUT .../manager`, `.manager-submit` `POST .../manager/submit`, `.send-back` `POST .../send-back`, `.close` `POST .../close`, `.reopen` `POST .../reopen`, `.skip` `POST .../skip`, `.restore` `POST .../restore`, `.reviewer` `PUT .../reviewer`.
